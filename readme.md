\# 資料結構主題測驗網站



本專案為 Django 製作的資料結構主題測驗網站，提供學生進行資料結構相關測驗練習。題目涵蓋陣列、鏈結串列、堆疊、佇列、樹、圖形、排序與搜尋等單元。



\ 一、系統功能



\ 1. 題庫管理

\- 可透過 Django Admin 新增、編輯與刪除題目。

\- 每一題可設定題目內容、章節、選項、正確答案、詳解與難易度。

\- 題目難易度分為：易、中、難。



\ 2. 測驗功能

\- 學生可選擇每次測驗題數：5 題、10 題、15 題或 20 題。

\- 系統會隨機出題。

\- 選項會隨機排列，但「以上皆非」會固定在最後。

\- 測驗頁面具有倒數計時功能，時間到會自動送出。



\ 3. 測驗結果

\- 測驗送出後會顯示總分。

\- 分數以 100 分制呈現。

\- 結果頁會顯示每一題的：

&#x20; - 答對或答錯

&#x20; - 我的答案

&#x20; - 正確答案

&#x20; - 詳解

&#x20; - 題目難易度



\ 4. 作答記錄

\- 系統會保留每次正式測驗的作答記錄。

\- 作答記錄包含測驗時間、得分、題目、我的答案、正確答案、答題結果與詳解。



\ 5. 錯題複習

\- 學生可針對當次正式測驗答錯的題目進行錯題複習。

\- 錯題複習送出後會顯示答對題數與錯題總數。

\- 錯題複習主要作為練習用途。



\ 6. 間隔學習法

\- 系統會記錄學生在正式測驗中答錯的題目。

\- 答錯的題目會在之後的正式測驗中優先再次出現。

\- 若學生之後答對該題，該題會從間隔學習錯題清單中移除。
